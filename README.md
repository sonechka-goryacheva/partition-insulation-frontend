# partition-insulation-frontend

Фронтенд курсового проекта «Расчёт звукоизоляции перегородок». Ветка `partition-react-mock` — лабораторная работа №5: базовое SPA на React для гостя.

В ЛР-5 приложение работает **только на mock-данных**: без веб-сервиса, базы данных и MinIO. Доступны две страницы — «Плитка конструкций» и «Лента конструкций»; пункты меню «Добавить» и «Войти» пока недоступны.

## Стек

|---|---|
| Node.js | 24 |
| React | 19.3.1 |
| TypeScript | 6.0.3 |
| Vite | 8.3.5 |
| React Router (react-router-dom) | 7.18.4 |
| React-Bootstrap | 2.10.10 |

Оформление перенесено из ЛР-2: акцентный цвет `#EE4623`, тёмные шапка и нижнее меню, прямые углы, шрифт Montserrat. Макет — вертикальный экран телефона шириной 390 px по центру окна.

## Запуск

Локально (приложение откроется на http://localhost:3000):

    npm install
    npm run dev

В Docker:

    docker compose up --build

Сборка и проверка кода:

    npm run build
    npm run lint

## Нижнее меню

Закреплено внизу экрана на всех страницах, 4 пункта:

| Пункт | Доступность | Действие |
|---|---|---|
| Лента | доступен | открывает ленту с первой конструкции текущего списка |
| Добавить | недоступен (бледный, не нажимается) | — |
| Плитка | доступен | открывает плитку конструкций |
| Войти | недоступен (бледный, не нажимается) | — |

Пункт открытой страницы подсвечивается акцентным цветом.

## Страница «Плитка конструкций»

Адрес: `/`. Стартовая страница приложения.

**Шапка «Каталог перегородок»** с фильтром по индексу звукоизоляции Rw:

| Элемент | Тип | Описание |
|---|---|---|
| Индекс Rw не ниже | слайдер | нижняя граница Rw, дБ; справа показано текущее значение; по умолчанию 0 |
| Индекс Rw не выше | слайдер | верхняя граница Rw, дБ; по умолчанию наибольший Rw в коллекции (74) |
| Подписи 0 и 74 | текст | границы слайдеров |
| Поиск | кнопка | показывает конструкции, у которых Rw попадает в выбранный диапазон |

**Плитка** — карточки конструкций в две колонки. На карточке:

| Элемент | Описание |
|---|---|
| Фото | фото конструкции; если его нет или файл не загрузился — изображение по умолчанию «Фото недоступно» |
| Название | название конструкции |
| Толщина и Rw | строка вида «125 мм · Rw 52 дБ» |
| Лайки | сердечко и число лайков (у гостя только просмотр) |

Действия:
- нажатие на карточку — переход на страницу «Лента конструкций» с этой конструкцией;
- если ни одна конструкция не подходит под фильтр — сообщение «Конструкций с таким индексом Rw не найдено.».

## Страница «Лента конструкций»

Адрес: `/partition-feed/:partitionSystemId`. Страница «подробнее о конструкции» в формате ленты: одна конструкция на весь экран.

| Элемент | Тип | Описание |
|---|---|---|
| Медиа на весь экран | видео или фото | своё видео конструкции; если видео нет — её фото; если нет ни видео, ни фото — видео по умолчанию с фото по умолчанию в качестве обложки |
| Ромб с сердечком | показатель | число лайков |
| Ромб «Rw, дБ» | показатель | индекс звукоизоляции |
| Ромб «Толщ., мм» | показатель | толщина конструкции |
| Оранжевый ромб со стрелкой | кнопка «Далее» | следующая конструкция текущего списка; после последней — снова первая |
| Название | текст | название конструкции |
| Описание | текст | первые две строки описания |
| Ещё / Свернуть | кнопка | разворачивает и сворачивает описание полностью |
| Характеристики | список | дополнительные атрибуты конструкции: наименование, значение и единица измерения; если атрибутов нет — «Дополнительные характеристики не указаны» |

Если в плитке был применён фильтр, кнопка «Далее» листает только отфильтрованные конструкции. Если конструкции с указанным в адресе id нет — сообщение «Конструкция не найдена». Название открытой конструкции показывается в заголовке вкладки браузера.

## Mock-данные

Коллекция `PARTITION_SYSTEMS_MOCK` в `src/modules/partitionMock.ts` — 4 конструкции из ЛР-2: «Базовая 1», «Стандарт М1», «Газобетон D500», «Профи М1». Поля совпадают с ответом веб-сервиса ЛР-4, пустые значения — `null`:

| Поле | Тип | Описание |
|---|---|---|
| partitionSystemId | number | идентификатор конструкции |
| partitionName | string | название |
| partitionDescription | string \| null | описание |
| partitionThicknessMm | number \| null | толщина, мм |
| soundIndexRw | number \| null | индекс звукоизоляции Rw, дБ |
| partitionPhotoUrl | string \| null | путь к фото |
| partitionVideoUrl | string \| null | путь к видео |
| partitionLikesCount | number | число лайков |
| partitionIsLiked | 0 \| 1 | лайкнул ли текущий пользователь (у гостя 0) |
| partitionIsMine | 0 \| 1 | своя ли конструкция (у гостя 0) |
| partitionAttributes | массив | атрибуты: partitionAttributeId, partitionAttributeName, partitionAttributeUnit, partitionAttributeValue |

У конструкции «Газобетон D500» нет фото, видео и атрибутов — на ней видны фото и видео по умолчанию и сообщение «Дополнительные характеристики не указаны».
